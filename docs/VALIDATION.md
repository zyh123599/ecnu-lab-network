## 安全和可靠性边界

认证只发往固定的 `https://login.ecnu.edu.cn`，保留 TLS 证书验证，禁止自动重定向，不读取代理环境变量。不会打印学校返回的原始错误、密码、认证令牌或带认证参数的请求 URL。

账号配置是本地明文文件，并非加密保管；文件权限只限制普通用户访问，root 仍可读取。systemd 为服务复制凭据，更新账号后需要重启服务。

认证失败停止重试；网络故障退避重试。watch 的文件锁只能阻止同一 Linux 用户的重复 watch，不能阻止其他用户/其他脚本/其他机器争抢同一出口账号。实验室应只部署一个管理进程。
