## 适用范围

最低 Python 版本为 3.8，本地实际测试版本为 3.12。校园服务器的 Python、Linux 版本及校区尚未记录。其他校区、IPv6 和共享 NAT 出口未测试。

程序沿系统路由访问认证服务，不支持手动绑定网卡。watch 文件锁只限制同一 Linux 用户的重复进程，不协调其他用户或其他登录脚本。

自动重连和开机自启需在维护窗口继续验证，避免测试退出或重启影响正在使用服务器的人。
